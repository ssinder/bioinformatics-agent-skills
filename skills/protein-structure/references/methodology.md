# 方法学：蛋白质结构分析的算法与参数选择

本文说明 `protein-structure` 技能中每一步计算所依据的公式、算法选择理由，
以及关键参数的取值依据。阅读本文后应能独立复现或调整这些分析。

## 1. PDB 文件解析

### 1.1 固定列解析

PDB v3.3 的原子记录采用固定列宽格式，本技能按列切片解析（0-based）：

| 字段 | 列范围 | 说明 |
|---|---|---|
| record | `[0:6]` | `ATOM` / `HETATM` |
| serial | `[6:11]` | 原子序号 |
| name | `[12:16]` | 原子名（含元素对齐空格） |
| altLoc | `[16]` | 交替位置标记 |
| resName | `[17:20]` | 残基名 |
| chainID | `[21]` | 链标识 |
| resSeq | `[22:26]` | 残基序号 |
| iCode | `[26]` | 插入码 |
| x, y, z | `[30:38] [38:46] [46:54]` | 坐标（Å） |
| occupancy | `[54:60]` | 占据率 |
| tempFactor | `[60:66]` | B 因子 |
| element | `[76:78]` | 元素符号 |

**为什么用列切片而不是空格分割**：原子名可能含空格（` CA `、` HG `），
且坐标列没有分隔符。空格分割会在含金属配位（` CA ` 同时是钙离子与 α-碳）
或侧链命名（`1HB`）的文件上出错。

**元素推断**：当 `element` 字段为空时，从原子名推断。若原子名首字符是数字
（如 `1HB`），取第二位字符；否则取首字符大写。这与 PDB 编写规范一致。

### 1.2 交替位置（altLoc）

同一残基可能存在多个构象（侧链旋转异构体）。本技能只保留 `altLoc` 为
空、空格、`A` 或 `1` 的构象——即晶体学主构象。

**参数影响**：若结构完全由 altLoc 构成（例如 NMR 集合结构），保留策略会
丢弃部分原子。选择依据是"主构象优先"这一通用惯例；如需全部构象，应改用
Biopython 的 `DisorderedAtom` 处理。

### 1.3 多模型

`MODEL` / `ENDMDL` 记录切分模型。默认分析第一个模型（`--model 1`），
因为 NMR  ensembles 的后续模型通常是次优解。

## 2. 几何计算

### 2.1 回旋半径（Radius of Gyration, Rg）

质量加权定义：

```
Rg = sqrt( Σᵢ mᵢ |rᵢ - R_cm|² / Σᵢ mᵢ )
```

其中 `R_cm` 为质量质心。**质量加权**而非等权，因为质子与碳原子的质量差异
会显著影响结果（仅重原子等权计算得到的 Rg 偏小约 5-10%）。

本技能同时给出：

- `rg`：全原子质量加权 Rg
- `rg_ca`：仅 Cα 子集的 Rg（文献中常引用这种定义，两者差异可达 5%）
- `rg_components`：沿主惯性轴的 Rg_x / Rg_y / Rg_z

原子质量取标准原子量；元素缺失时按碳处理。

### 2.2 陀螺张量与形状描述符

陀螺张量：

```
S = Σᵢ mᵢ (rᵢ - R_cm)(rᵢ - R_cm)ᵀ
```

对称 3×3 矩阵，用 **Jacobi 旋转法** 做特征分解（纯 Python 实现，最多 100 次
扫描，收敛阈值 1e-12）。特征值降序记为 `λ1 ≥ λ2 ≥ λ3`，对应最长、中等、
最短主轴。

形状描述符：

| 量 | 公式 | 含义 |
|---|---|---|
| 非球形性 asphericity | `b = λ1 - λ2` | 棒状程度，球形为 0 |
| 非圆柱性 acylindricity | `c = λ2 - λ3` | 盘状程度 |
| 相对形状各向异性 | `κ = 0.5 (b² + c²) / Rg⁴` | 0 = 完美球形，1 = 理想棒形 |

**形状分类判据**（经验值）：

- `b / Rg² < 0.01` → 球形（sphere）
- `c / Rg² < 0.05` → 棒形（rod）
- 其他 → 卷曲（coil）

折叠球状蛋白通常 `κ < 0.1`；伸长的 coiled-coil 或纤维状蛋白 `κ > 0.4`。

### 2.3 瞬时偶极矩

```
μ = Σᵢ qᵢ (rᵢ - R_cm)
```

使用**元素级简化部分电荷**（H +0.31、C +0.05、N -0.30、O -0.42、S -0.20 等）。
这是数量级的粗略估计，只适合体系之间的相对比较，**不应与 QM 计算的偶极矩
直接对照**。若需要精确值，应从力场拓扑读取每原子电荷。

### 2.4 二面角计算

采用 IUPAC 约定（从 `p1` 看向 `p2` 时为负）：投影法——把 `p0-p1` 与 `p3-p2`
投影到垂直于主轴 `p1→p2` 的平面上，投影向量夹角即为扭转角，符号由
`(axis × v) · w` 决定。

**验证**：该实现与 praxeolitic 公式在 200 组随机点上位数精度完全一致。

## 3. 二级结构判定

### 3.1 通路 A：外部 DSSP

调用系统中的 `mkdssp`（新版）或 `dssp`，命令形式：

```
mkdssp <pdb> -o <out.dssp>
```

解析传统 DSSP 文本格式，关键列为残基号 `[5:10]`、链标识 `[11]`、
氨基酸 `[13:16]`、二级结构码 `[16:17]`。

**DSSP 代码含义**：

| 码 | 含义 | 归类 |
|---|---|---|
| H | α-螺旋 | 螺旋 |
| G | 3-10 螺旋 | 螺旋 |
| I | π-螺旋 | 螺旋 |
| E | 折叠股 | 折叠 |
| B | β-桥 | 折叠 |
| T | 转角 | 卷曲 |
| S | 弯折 | 卷曲 |
| - / 空格 | 无规卷曲 | 卷曲 |

### 3.2 通路 B：内置简化 DSSP

无外部程序时的回退实现，步骤如下。

#### 步骤 1：重建酰胺氢

X 射线与 NMR 结构通常**不含极性氢原子**，但 DSSP 的氢键判定需要 N-H 供体。
本技能用几何法重建虚拟氢：

设 `u1` = N→C(prev) 单位向量，`u2` = N→CA 单位向量，
`θ = angle(u1, u2)`，`e2` 为 `u2` 在垂直于 `u1` 平面内的单位分量。
肽键平面性保证 N 上三条键共面，于是：

```
h_dir = cos(119°)·u1 + [cos(119°)·(1 - cosθ) / sinθ]·e2
H = N + 1.00 Å · ĥ
```

其中 119° 是 N-H 与 N-C(prev) 的键角（N-CA-C 约 111.2°，CA-C-N 约 116.2°，
三者加和约 360°，符合平面三价氮）。

**验证**：在理想 α-螺旋上，重建氢与羰基氧的距离使 O(i)···N(i+4) ≈ 3.09 Å，
正是 DSSP 判据所需的接触。

#### 步骤 2：Kabsch-Sander 氢键能量

```
E = -27.888 · (1/r_ON + 1/r_CH)
  + 332.0  · (q1·q2f / r_ON + q1f·q2 / r_CH)
  + 0.20   · q1f·q2f · (1/r_ON + 1/r_CH)
```

- `q1` = 供体 N 上的部分电荷（0.20 + 侧链修正）
- `q2` = 受体羰基 C 上的部分电荷（0.20 + 侧链修正）
- `q1f` / `q2f` = 侧链诱导的等效电荷
- `r_ON` = N···O 距离，`r_CH` ≈ `r_ON + 0.2`（近似值）

侧链修正（本技能采用的简化版）：Asp/Glu 取 -0.5，His 取 -0.5，
Lys/Arg 取 +0.5，其余为 0。

**阈值选择**：默认 `--hbond-energy -0.5`（kcal/mol）。

- 更严格（-1.0）：只保留最强氢键，螺旋片段更短、更保守
- 更宽松（-0.2）：螺旋片段更长，可能过度延伸
- DSSP 原始实现对能量低于 -0.5 kcal/mol 的氢键计数，与此默认一致

#### 步骤 3：氢键模式分类

设残基在链内的位置为 `pos`。**关键方向性约束**：蛋白质的右手螺旋拓扑
要求受体的 C=O 位于供体 N-H 的**上游**，即 `pos_acceptor < pos_donor`。
缺少这一约束会把 i→i+1 的相邻残基误判为氢键。

据此判定：

| 模式 | 代码 |
|---|---|
| `i → i+4`（供体 i，氢键到受体 i-4） | H（α-螺旋） |
| `i → i+3` | G（3-10 螺旋） |
| `i → i+5` | I（π-螺旋） |
| 平行桥（i→j 且 i+1→j+1） | B（β-桥） |
| 反平行桥（j→i 且 j→i-1） | B（β-桥） |

β-桥的判定严格遵循 DSSP 定义：两个残基间存在直接氢键，且**相邻残基也**
存在相应方向的氢键，才算一个完整桥（否则只是单个接触）。

#### 步骤 4：转角与弯折

未被上述模式覆盖的残基按 DSSP 优先级归类：

1. φ/ψ 落在 β 区（φ ∈ [-180, -20]，ψ > 30）→ **E**（折叠股）
2. φ/ψ 落在 α 区（φ ∈ [-160, -20]，ψ ∈ [-120, 30]）→ **H**
3. 存在 `i → i+2` 的 n-turn 氢键 → **T**（转角）
4. `|φ| > 90` 且 `|ψ| > 90` → **S**（弯折）
5. 其余 → **-**（无规卷曲）

**优先级说明**：伸展链的 ψ ≈ +135° 且形成 i→i+2 氢键，若先判转角会得到
大量 `T`，掩盖真实的折叠股特征。因此 β 区优先于转角。

### 3.3 两种通路的取舍

| 场景 | 建议 |
|---|---|
| 需要发表级二级结构标注 | 用外部 DSSP（`--dssp-method external`） |
| 无 DSSP 环境 / 批量快速筛查 | 用内置实现（`--dssp-method builtin`） |
| 结构含显式氢原子 | 内置实现更准（直接用文件中的 H，不重建） |
| 结构分辨率低、氢键距离临界 | 用内置实现并放宽 `--hbond-energy` 到 -0.2 |

内置实现**不**计算水桥、π-堆积等二级结构相关的精细项，
因此在 β-折叠股内部可能给出 `T`/`-` 而非连续的 `E`。

## 4. UniProt 元数据

使用 REST API：

```
GET https://rest.uniprot.org/uniprotkb/search
    ?query=accession:P69905 OR accession:P02340
    &format=json
    &fields=accession,id,protein_name,...
```

- 批量查询时每批最多 100 个 accession，避免 URL 过长
- 通过共享层 `biopipe_core.http_session` 发起请求，自带指数退避重试
  （4 次，退避基数 2.0）与最小请求间隔 0.34 s（NCBI/UniProt 速率限制友好）
- 网络失败时**静默降级**：记录 warning，主流程继续，不影响结构分析结果

提取字段：accession、entry_name、entry_type、protein_name、gene_names、
organism_name、organism_id、length、mass、function、keywords、go_terms。

## 5. 批量统计

`batch_analyze.py` 用线程池并发处理（纯计算任务在 CPython 下受 GIL 限制，
加速比有限；但文件 IO 与解析的组合仍有收益）。汇总统计包括：

- 长度分布（<100 / 100-200 / 200-300 / 300-500 / ≥500）
- 链数分布
- 平均残基数、平均原子数、平均 Rg 及其标准差
- 整体螺旋 / 折叠 / 卷曲百分比（按残基加权，而非按结构平均）
- DSSP 方法使用分布（便于确认有多少结构走了外部通路）
