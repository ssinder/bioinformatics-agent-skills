# 科学图表方法学原理与规范

本文说明 `scientific-figures` 技能的视觉规范、各图类型的统计方法与色板选择依据。

---

## 1. 出版级视觉规范

### 1.1 字体

```
font.family      = sans-serif
font.sans-serif  = ['Arial', 'Helvetica', 'DejaVu Sans']
```

Arial 是生命科学期刊最通用的无衬线字体；Helvetica 作为 macOS 回退，
DejaVu Sans 是 Linux 上 matplotlib 自带的最终回退，保证在任何系统上都不会
因找不到字体而崩溃（matplotlib 会退回到默认字体并给出 warning）。

`mathtext.fontset = 'dejavusans'` 让公式渲染风格与正文一致，避免
DejaVu 数学字体与 Arial 正文混排时的突兀感。

### 1.2 坐标轴与网格

```
axes.spines.top    = False
axes.spines.right  = False
axes.grid          = False
axes.axisbelow     = True
```

去除 top/right spines 是"去框架化"（frameless）风格的核心：读者只需两条
基线就能定位数值，视觉负担更小。默认关闭网格线，因为网格会与数据线竞争
注意力；只有在需要精确读数时才临时开启。

`axes.axisbelow = True` 保证网格线（若开启）绘制在数据之下。

### 1.3 线宽与字号比例

基础样式：线宽 2.0、marker 大小 6、刻度标签 9、轴标签 11、标题 12。
期刊预设会整体缩放：

| 预设 | 正文字号 | 轴标签 | 保存 dpi |
| --- | --- | --- | --- |
| `default` | 10 | 11 | 300 |
| `nature` | 7 | 8 | 600 |
| `cell` | 8 | 9 | 600 |
| `science` | 9 | 10 | 600 |

期刊预设的意义：Nature 类期刊双栏版面单栏宽度约 89 mm（约 3.5 英寸），
7 pt 字号在这个宽度下才不显得过大；Cell 用 8 pt；Science 单栏稍宽用 9 pt。

**画布尺寸**：`setup_single_figure(width=3.5, height=2.8)` 默认是 Nature 单栏
尺寸（89 mm × 71 mm）。整页图用 `setup_multi_panel(width=7.0)`（约 180 mm 双栏）。

### 1.4 保存

```
savefig.dpi     = 300 / 600
savefig.bbox    = 'tight'
savefig.pad_inches = 0.1
savefig.facecolor = 'white'
```

- **300 dpi** 是多数期刊对位图的最低要求；线稿类图表建议 600 dpi
- **PDF（矢量）** 是投稿的首选：任意缩放不失真、文件体积小、可在 Illustrator
  中二次编辑
- **tight bbox** 会裁掉多余的白色边缘，但如果图中有本应保留的空白会被误裁，
  此时用 `save_figure(..., bbox_inches=None)` 关闭

### 1.5 色板

| 调色板 | 用途 |
| --- | --- |
| `okabe_ito` | **分类数据首选**。Okabe & Ito (2008) 设计的色盲友好调色板，8 色在各类色觉缺陷下都可区分 |
| `tol_muted` | Paul Tol 的柔和调色板，9 色，适合需要区分度但不想太抢眼的场合 |
| `paper` | 项目主色（浅蓝/青/金/玫红 + 扩展色），浅色调适合大面积填充 |
| `high_contrast` | 仅 3 类时使用（深蓝/金/紫），对比最强 |

**为什么不用 jet/rainbow**：这类色阶不是感知均匀的，且在灰度打印或色觉缺陷
条件下会丢失区分度。连续数据统一用 `viridis`（感知均匀、色盲友好）。

### 1.6 语义色

```
high     = #44AA99   绿（高置信 / 高表达）
medium   = #88CCEE   蓝（中）
low      = #DDCC77   黄（低）
negative = #0072B2   深蓝
positive = #D55E00   橙红
accent   = #CC6677   玫红（均值线、强调）
```

pLDDT 的三档配色与 AlphaFold 官方分档（>90 很可靠 / 70–90 可靠 / <70 低）
保持一致，方便读者把图与结构预测数据库对照。

## 2. ROC 曲线

### 2.1 AUC 计算

脚本用**梯形法**从曲线点直接积分：

```
AUC = Σ (FPR[i+1] - FPR[i]) × (TPR[i] + TPR[i+1]) / 2
```

这与 sklearn 的 `roc_auc_score` 在点密集时结果一致。若输入 CSV 里已有 `AUC`
列，脚本优先使用该列；没有则自己算。

**必须包含 (0,0) 与 (1,1) 两个端点**，否则面积会偏差。

### 2.2 AUC 差异显著性检验

用 Hanley & McNeil (1982) 的 AUC 标准误公式做 Z 检验：

```
Q1 = A / (2 - A)
Q2 = 2A² / (1 + A)

SE(A) = √[ (A(1-A) + (n-1)(Q1 - A² + Q2 - A⁴)) / (n-1) ]
```

两个 AUC 的差异：

```
SE_diff = √(SE₁² + SE₂²)
z       = (AUC₁ - AUC₂) / SE_diff
p       = 2 × (1 - Φ(|z|))
```

**关键限制**：公式中的 `n` 是**样本量**，不是曲线点数。脚本用 `--n-samples`
（默认 500）作为假设值。必须传真实的验证集样本数，否则 p 值会失真。

显著性标记：`*` p<0.05、`**` p<0.01、`***` p<0.001、`ns` 不显著。

### 2.3 自助法置信区间

对 (FPR, TPR) 点对做有放回重采样（默认 200 次），每次重算 AUC，取
2.5% 与 97.5% 分位数。

这是**曲线点自助法**（curve bootstrapping），与基于原始预测分数的
bootstrap 不同：前者只能捕获曲线的采样不确定性，不能捕获模型训练集
采样的不确定性。两者都不替代独立验证集。

### 2.4 绘图细节

- 随机基线用黑色虚线，标注 `AUC = 0.50`
- `--fill-best` 用 10% 透明度填充最佳模型曲线下方
- 坐标范围 `[-0.02, 1.02]` 留出边距，避免曲线端点被 spines 裁切

## 3. 混淆矩阵

### 3.1 矩阵布局

```
        Pred Neg   Pred Pos
Actual Neg   TN        FP
Actual Pos   FN        TP
```

注意很多论文把行/列顺序写成 `[TP, FN; FN, TP]`（预测为行），
与此处**实际为行**不同。两种都常见，但正文描述必须与图一致。

### 3.2 全局统一色阶

脚本对所有子图使用同一个 vmin/vmax（取全部子图值的最小/最大），
这样不同模型之间的格子颜色**可以直接横向比较**。

若每个子图各自归一化，视觉上会显得"每个模型都差不多好"，掩盖真实差异——
这是混淆矩阵图最常见的误导方式。

### 3.3 双标注

格子里同时显示绝对值与百分比：

```
85
(41.5%)
```

百分比 = 该格 / (TN+FP+FN+TP)。文字颜色按格子值与色阶中点比较自动选黑/白，
保证对比度。

## 4. 热图

### 4.1 色阶裁剪

对接结合能这类数据常有极端离群值（-15 kcal/mol vs -5 kcal/mol），
线性色阶会让所有正常值挤在同一个颜色区间。

**分位数裁剪**：vmin = 2% 分位，vmax = 98% 分位。超出范围的格子落在色阶
边界（颜色饱和），需要在图注中说明"色阶按 2–98 百分位显示"。

### 4.2 方向语义

结合能是负值，越负表示结合越强。脚本默认 `coolwarm_r`（反向）：
- 红 = 低值（强结合）
- 蓝 = 高值（弱结合）

这符合"热 = 强"的直觉。若数据是相关性（正负都有），用 `coolwarm`（正向）：
红 = 正相关，蓝 = 负相关。

### 4.3 标签抽样

行列标签过多时无法全部显示。脚本按 `max(1, n//20)` 抽样 X 轴、
`max(1, n//25)` 抽样 Y 轴，避免字体重叠。

## 5. pLDDT 置信度分布

### 5.1 官方分档

| pLDDT | AlphaFold 官方描述 |
| --- | --- |
| > 90 | Very high confidence, typically a correct and reliable backbone |
| 70–90 | Confident, generally reliable backbone |
| 50–70 | Low confidence, often incorrect or unreliable |
| < 50 | Very low confidence, usually very low quality |

脚本用三档（>90 / 70–90 / <70），因为 50 分界在短蛋白里意义不大。

### 5.2 统计标注

图中同时标注：
- 均值（玫红虚线）
- 中位数（浅蓝点线）
- 三档占比 + 样本量 N（文本框）

均值与中位数分开标注是因为 pLDDT 分布常左偏（大量高置信 + 少量低置信），
两者差异大时能立刻看出来。

## 6. SHAP 摘要图

### 6.1 特征重要性

```
mean|SHAP| = (1/n) Σ |shap_value_i|
std|SHAP|  = 标准差(|shap_value|)
```

`mean|SHAP|` 是 Shapley 值的经典全局重要性度量（Shapley 1953）。

### 6.2 蜂群图（beeswarm）

每个特征一行，每个样本一个点：
- **横坐标**：SHAP 值（正值推高预测，负值压低）
- **纵向抖动**：随机偏移，避免点完全重叠（随机种子固定为 `42 + feature_index`，
  保证可复现）
- **颜色**：按该样本的 SHAP 值本身着色（coolwarm），因此
  "红点集中在右侧"表示高 SHAP 值的样本贡献更大

### 6.3 与重要性条形图的关系

两张图**必须共用同一 Top-N 特征列表和同一顺序**，否则读者无法把
蜂群图中的某一行对应到重要性条形图的某一条。脚本通过共享 `top_features`
变量保证这一点。

### 6.4 与 shap 库的区别

真正的 `shap.summary_plot` 用核密度估计做"蜂群"排布（高密度处点更密），
本脚本用的是随机抖动（点密度均匀）。视觉上会略有差异，但数值含义完全一致。
若需要与 shap 库的结果逐像素对比，请改用 shap 库。

## 7. 分类分布图

### 7.1 双层级结构

按 (kingdom, phylum, class) 聚合后展示 Top N 个 class，柱子颜色按 phylum 区分，
标签显示 `数值 [界-门]`。这样一张图同时传达三个分类层级的信息。

### 7.2 X 轴留白

`ax.set_xlim(0, max_val * 1.55)` 预留 55% 的横向空间给标签文字。
如果标签仍被裁切，增大这个倍数或缩短 label（脚本已对超过 28 字符的
类名做截断）。

## 8. 通用原则

### 8.1 数据-墨水比

每一笔像素都应承载信息。网格线、冗余边框、深色背景都属于"墨水"但
不承载信息，因此默认关闭。

### 8.2 颜色只编码一个变量

一张图里颜色应只对应一个维度（如"不同模型"或"不同分类"）。若同时用颜色
表示类别和大小，就无法解码。

### 8.3 图注承担解释责任

图上的数字是"what"，图注要写清"how"：数据来源、样本量、统计方法、
色阶范围与裁剪方式、缩写含义。脚本生成的统计文本框是图注的初稿。

### 8.4 灰度可读性

投稿时部分期刊会黑白印刷。用 Okabe-Ito 色板的原因之一就是它在
灰度转换后各色的明度仍有区分度。可用 `--formats png pdf` 额外导出，
自行转灰度检查一遍。
