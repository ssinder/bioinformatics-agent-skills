# 多肽分析方法学原理与参数选择

本文说明 `peptide-design` 技能中每个计算环节的公式来源、适用边界与参数调优依据。

---

## 1. 分子量

### 公式

```
MW = Σ(各残基的平均游离基团质量) + H2O 的质量
```

残基质量表使用 20 种标准氨基酸的平均游离基团质量（Kyte & Doolittle 1982 体系），
水质量取 18.0153 Da。

**为什么加一分子水**：氨基酸之间形成肽键时每缩合一分子水。n 个残基形成链状肽
丢失 n-1 分子水，但用"游离基团质量"表时每个残基本身已扣除一分子水，因此
只需在总和上加回一分子水。

### 单同位素质量

用于质谱（MS/MS）数据库匹配：

```
MW_mono = Σ(单同位素残基质量) + 18.01056
```

单同位素质量**小于**平均质量，两者差值（~0.5–1 Da/残基）随肽长累积。
用平均质量去搜质谱库会系统性偏移，长肽（>30 aa）尤其明显。

### 边界

- 非标准残基（X/B/Z/U）按母体最保守近似计：X 用 Gly（57.0519）
- 二硫键：每形成一对 C-S-S 键，分子量减少约 2.016 Da（脚本的 `disulfide_bonds`
  字段给出的是**潜在**二硫键数，实际成键与否取决于氧化环境）

## 2. 等电点（pI）

### 电荷模型

Henderson-Hasselbalch 方程：

```
[去质子化形式] / [质子化形式] = 10^(pH - pKa)
```

各基团的净电荷贡献：

| 基团 | pKa | 电荷贡献 |
| --- | --- | --- |
| N 端 α-氨基 | 8.0 | +1 × 1/(1+10^(pH-8.0)) |
| Lys 侧链 ε-氨基 | 10.5 | +1 × 1/(1+10^(pH-10.5)) |
| Arg 侧链胍基 | 12.5 | +1 × 1/(1+10^(pH-12.5)) |
| His 侧链咪唑基 | 6.0 | +1 × 1/(1+10^(pH-6.0)) |
| C 端 α-羧基 | 3.0 | -1 × 1/(1+10^(3.0-pH)) |
| Asp 侧链 | 3.9 | -1 × 1/(1+10^(3.9-pH)) |
| Glu 侧链 | 4.1 | -1 × 1/(1+10^(4.1-pH)) |
| Cys 侧链 | 8.3 | -1 × 1/(1+10^(8.3-pH)) |
| Tyr 侧链 | 10.1 | -1 × 1/(1+10^(10.1-pH)) |

净电荷 = 正贡献总和 - 负贡献总和。

### 求解 pI

1. 在 pH 0–14 范围内以 0.1 为步长扫描，得到 141 个 (pH, 电荷) 采样点
2. 找到电荷符号翻转的相邻区间 [pH_lo, pH_hi]
3. 在该区间内**二分 60 次**求解电荷为零的精确解（收敛到 1e-15 量级）

**为什么不直接线性插值**：电荷-pH 曲线在缓冲区间（pKa 附近）是 S 形而非直线，
线性插值在极端 pH 区域会有明显偏差。二分法直接解 f(pH)=0，无需额外假设。

### pKa 的局限

pKa 值随温度、离子强度、邻近基团与末端修饰而变。本实现使用 25 °C 的文献
标准值，对游离端基的短肽误差通常在 ±0.5 个 pH 单位内。若序列含大量 His
（His 的 pKa 对环境极敏感）或使用了脂化/酰胺化等修饰，需用专业工具（如
PROPKA、ProteinCalculator）重新计算。

## 3. 疏水性

### Kyte-Doolittle 平均疏水性（KD）

Kyte & Doolittle (1982) 用水合自由能定量标度 20 种氨基酸的疏水性：

```
Ile 4.5 > Val 4.2 > Leu 3.8 > Phe 2.8 > Cys 2.5 > Met 1.9 > Ala 1.8
  > Gly -0.4 > Thr -0.7 > Ser -0.8 > Trp -0.9 > Tyr -1.3 > Pro -1.6
  > His -3.2 > Glu -3.5 = Gln -3.5 = Asp -3.5 = Asn -3.5 > Lys -3.9 > Arg -4.5
```

序列平均疏水性 = 各残基 KD 值之和 / 有效残基数。

**解读参考**：

| 平均 KD | 含义 |
| --- | --- |
| > 4.5 | 极疏水，易聚集、易溶于非极性溶剂 |
| 1.8 – 4.5 | 疏水（典型跨膜段） |
| 0 – 1.8 | 中性偏疏水 |
| -0.5 – 0 | 略亲水 |
| < -0.5 | 强亲水（水溶性球状肽） |

### 疏水矩（Hobbs et al. 1984）

```
μ_H = |Σ_i h_i · e^(iθ_i)| / |Σ_i h_i|

其中 h_i 为第 i 个残基的 KD 值
θ_i = 2πi / N
```

疏水矩刻画**疏水残基沿肽链的周期性分布**。一个两性肽在 3.6 残基/圈的
α 螺旋周期上会形成明显的疏水面，此时 μ_H 显著高于同 KD 平均值的随机序列。

**判别两性肽的组合条件**（脚本采用）：

```
μ_H ≥ 0.4  且  |净电荷(pH 7)| ≥ 1.0
```

单看 KD 无法区分"整体疏水"与"疏水/亲水两面"，疏水矩提供了这个信息。

## 4. 不稳定指数

### Guruprasad, Reddy & Pandit (1990)

```
II = (100 / L) × Σ(i=2..L) DIHEX(di-1, di)
```

DIHEX 是二面角不稳定权重表（每个残基对相邻残基的乘性贡献），
取值 0.59（Gly）到 1.48（Asn）。

**判读标准**（作者原文）：

| II 值 | 预测 |
| --- | --- |
| < 40 | 稳定 |
| > 40 | 不稳定 |

该公式源自蛋白（长肽），用于 20 aa 的短肽时**指示性偏弱**。短肽的稳定性
更多取决于是否形成二硫键、是否被蛋白酶降解、疏水性驱动的聚集倾向，而非
二面角柔性。脚本用 `qc_flags` 提示这一情况而不自动剔除。

## 5. 芳香性与脂肪族指数

### 芳香性

```
aromaticity = (Phe + Trp + Tyr + His) / L
```

Cornwell et al. (2013) 用这个简化式描述蛋白的芳香性含量。对多肽，
芳香残基参与膜插入与自由基生成，是抗菌机制中的双刃剑——适量有利抗菌，
过高则增加非特异性毒性。

### 脂肪族指数

```
AI = 100 × (Ala + Val + Ile + Leu) / L
```

Ala、Val、Ile、Leu 的体积与形状使 α 螺旋倾向较高，因此 AI 是螺旋形成
能力的粗略预测。AI > 100 的肽通常偏好 α 螺旋。

## 6. 二级结构倾向（Chou-Fasman）

每个残基有三个构象参数：螺旋倾向 `Pα`、折叠倾向 `Pβ`、拐角倾向 `Pγ`。

归一化：

```
helix_fraction = Σ(Pα_i) / Σ(Pα_i + Pβ_i + Pγ_i)
```

螺旋倾向还做了**终止残基修正**：

```
helix_propensity = helix_fraction
                 - (Pro + Gly + 0.5×Cys + 0.5×Asn) / L
```

Pro 与 Gly 是强螺旋终止残基（Pro 无酰胺氢，Cys/Asn 的侧链会影响主链氢键）。

**局限**：Chou-Fasman 是单残基统计方法，不考虑长程相互作用。对多肽这种
缺少三维结构约束的体系，预测精度有限，只能作为粗筛依据。

## 7. 溶解度

Zhao (2009, Protein Sci) 的序列依赖回归模型：

```
lnS = 0.480 + 0.084·√N + Σ_i(残基级 log-s 贡献) + 0.20·helix_fraction
```

其中残基级贡献来自 Zhao 的实验标定表（如 Trp -0.585、Phe -0.701、
Arg -0.418、Ser -0.129 等）。

**为什么要加长度项**：短肽在同等组成下溶解度更高（端基效应 + 更少疏水
残基接触），`0.084·√N` 刻画了这一趋势。

**螺旋项**：α 螺旋结构比无规卷曲更利于溶解（内部氢键把疏水残基藏在内部），
故给 +0.20 × helix_fraction。

**返回值的含义**：是 log-s 值（对数尺度），不是直接的质量溶解度（g/L）。
跨序列比较大小即可，不要当作绝对溶解度读。

## 8. Boman 值

Boman et al. (1993) 从 24 种已知抗菌肽与 40 种非抗菌肽中统计出各残基的
"潜在抗菌倾向"权重：

```
Boman值 = Σ(各残基权重)
```

正权重（疏水残基）：Leu/Ile 4.92、Met 4.55、Val 4.71、Phe 4.14
负权重（带电残基）：Arg -2.21、Asp -1.83、Asn -1.60、Glu -1.53、Lys -1.27

**原理**：抗菌肽的作用机制是插入并破坏负电的细菌膜，因此疏水残基贡献正
权重、带电残基贡献负权重。总和越大，潜在膜结合与破坏能力越强。

**局限**：Boman 值只看组成不看排列，对两性肽的空间呈现无法判断；
且原始标定来自特定肽库，对抗真菌肽的适用性弱于抗细菌肽。

## 9. 抗菌肽判别规则

### 注释层（权重 0–20 分）

| 类别 | GO 术语 / 关键词 | 分值 |
| --- | --- | --- |
| 直接抗菌 | GO:0042742 / GO:0050830 / GO:0050832 / GO:0050829 / GO:0045087；Antimicrobial / Defensin / Bacteriocin / Antibiotic | GO 5.0 / 关键词 4.0 |
| 杀伤 | GO:0031640 / GO:0051715 / GO:0019875 | 5.0 |
| 毒素 | GO:0090729 等 8 项；Toxin / Hemolysin / Venom 等 | GO 4.0 / 关键词 3.0 |
| 免疫 | GO:0006952 / GO:0006955 等；Immunity / Defense | GO 3.0 / 关键词 2.0 |
| 其他防御 | Plant defense / Fungicide / Wound healing 等 | 2.0 |
| 抗病毒 | GO:0019048 等；Virulence / Viral / Viral protein 等 | GO 2.0 / 关键词 2.0 |

### GO 三大类别的还原

判别只关心具体 GO 编号，但报告里的「GO 注释覆盖度」需要区分分子功能（F）/
生物过程（P）/细胞组分（C）。输入有两种常见形态，技能都能处理：

| 输入形态 | 还原方式 |
| --- | --- |
| 已有 `go_molecular_function` / `go_biological_process` / `go_cellular_component` 三列 | 直接沿用 |
| 只有合并的 `go_terms` 列，条目带 `F:` / `P:` / `C:` 前缀（UniProt GoTerm 属性原始格式） | 按前缀切分 |
| 只有合并的 `go_terms` 列，只有 `GO:xxxxxxx: term name` | 回退到内置的 `GO_ASPECT_HINTS` 速查表（覆盖 30 余个常用编号） |

三者都无法判定时归入 `unknown`，不计入三大类别覆盖度。

### 理化层（0–10 分）

| 规则 | 分值 |
| --- | --- |
| KD 在 1.0–4.0（疏水但不过强） | 2.0 |
| pH 7 净正电荷 > 0（膜结合关键） | 2.0 |
| 长度 12–50 aa（典型 AMP 长度） | 2.0 |
| 芳香性 0.05–0.25 | 1.0 |
| Boman 值 > 0 | 1.5 |
| 含半胱氨酸 | 0.5 |
| 不稳定指数 < 40 | 1.0 |

### 综合

```
total = 0.6 × annotation_score + 0.4 × physicochemical_score
```

**为什么注释层权重更高（0.6）**：GO 术语与关键词是实验验证过的功能注释，
证据强度高于理化性质的外推。纯 FASTA 输入（无注释）时注释层为 0，
总分会显著偏低——此时应把 `--antimicrobial-threshold` 降到 2.5–3.0。

**阈值调参**：

| 数据情况 | 建议阈值 |
| --- | --- |
| 有完整 GO + keyword | `--antimicrobial-threshold 5.0`（默认） |
| 有 GO 无 keyword | 4.0–4.5 |
| 仅 FASTA 序列（无注释） | 2.5–3.0 |
| 需要高特异度（少漏） | 提高到 6.0–7.0 |

## 10. 样本质量评分

```
quality_score = 存在水平分(0-40) + 序列完整性(±20) + 注释完整度(0-20) + 理化合理性(0-20)
```

**存在水平分**（UniProt proteinExistence）：

| 档位 | 分值 |
| --- | --- |
| Evidence at protein level | 40 |
| Evidence at transcript level | 25 |
| Protein inferred from homology | 15 |
| 其他有值 | 5 |

"Evidence at protein level" 意味着有实验直接证据蛋白存在，是构建高质量
负样本集的底线要求——一个只有转录本证据的"非抗菌肽"可能根本没被翻译过，
更谈不上有无抗菌活性。

**注释完整度**：每个 GO 术语 2 分、每个 keyword 1 分，封顶 20 分。

**理化合理性**：长度 8–60 aa 得 10 分；不稳定指数 < 40 得 10 分。

推荐 `--min-quality 60`（达到"蛋白水平证据 + 无未知残基 + 一定注释量"）。

## 11. 聚类算法

### MMseqs2 路径

```bash
mmseqs easy-cluster input.fasta clu tmp/ \
    --min-seq-id 0.3 -c 0.8 -s 7.5 --threads 4
```

| 参数 | 含义 | 建议 |
| --- | --- | --- |
| `--min-seq-id` | 簇内最小序列 identity | 短肽库用 0.3–0.5；长肽用 0.7+ |
| `-c` | 覆盖度（较短序列需覆盖较长序列的比例） | 0.8；短肽可降到 0.6 |
| `-s` | 灵敏度（7.0 快，7.5 平衡，8.0 慢而准） | 7.5 |

### 内置算法路径（回退）

1. **k-mer 签名**：k=3 的 3-mer 集合
2. **Jaccard 预筛**：`jaccard_lower = (min_id - w) / (1 - w)`，其中 w 是精确
   identity 的权重（0.5）。低于此下界的对直接跳过，避免 O(n²) 全量 LCS 计算
3. **精确 identity**：最长公共子序列（LCS）长度 / 较长序列长度，
   滚动数组实现，O(n·m) 时间、O(min(n,m)) 空间
4. **综合相似度**：`w × identity + (1-w) × Jaccard`，w 默认 0.5
5. **average-linkage（UPGMA）凝聚聚类**：Lance-Williams 更新公式

```
d(k, i∪j) = (n_i·d(k,i) + n_j·d(k,j)) / (n_i + n_j)
```

合并阈值 = 1 - min_identity。

### 代表序列选择

| 策略 | 逻辑 | 适用 |
| --- | --- | --- |
| `medoid` | 与簇内所有成员相似度之和最大者（最居中的序列） | 默认，保证代表性 |
| `longest` | 簇内最长序列 | 需要保留完整信息时 |
| `first` | 簇内第一条（保持输入顺序） | 与 MMseqs2 行为一致，便于对比 |

**medoid 为默认的理由**：最长序列未必最能代表簇内特征（可能只是 C 端延伸），
第一条则依赖输入顺序。medoid 是唯一在"代表性"意义上严格最优的选择。

## 12. 消光系数与浓度估算

```
ε280 = 5500 × nTrp + 1490 × nTyr     （还原型）
```

kD 估算用 Beer-Lambert 经验式：

```
kd = (ε × 0.1 / MW) / (1.342 + (ε/MW) - 1.5)
```

该经验式仅适用于含 Trp 的蛋白。**纯多肽若无 Trp 残基，ε280 接近 0，无法用
280 nm 测定浓度**——此时应改用 214 nm（肽键吸收，ε ≈ 30000 M⁻¹cm⁻¹）或
直接用荧光标记/氨基酸分析定量。
